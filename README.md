## 📌 Overview
**Net_Practice** is a system and networking project at 1337 (42 Network) aimed at teaching the fundamentals of TCP/IP networking, subnetting, and routing. 

As a Software Engineer working in a connected world, having a solid grasp of how data travels across networks is non-negotiable. This project provided hands-on experience in diagnosing and configuring network topologies.

## 💡 Core Concepts Explored
### TCP/IP Subnetting & Routing
**Definition:** Subnetting divides a large network into smaller, logical sub-networks. Routing directs data packets between these different networks.
**Problem Solved:** It solves the problem of IP address exhaustion and network congestion, organizing networks efficiently and ensuring data correctly reaches its intended destination across complex topologies.

## 🚀 Features
- **Subnetting Calculation:** Figuring out network masks, broadcast addresses, and usable IP ranges.
- **Routing:** Configuring routing tables to allow communication across different network interfaces and routers.
- **Troubleshooting:** Identifying flawed network configurations and applying the correct IPs/masks to establish connectivity.
